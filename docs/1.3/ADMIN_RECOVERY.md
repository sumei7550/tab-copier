# 管理员恢复购买页面

本版本用于现有沙盒环境。访问 `/admin/recovery`，无需在电脑上重新保存 PayPal 或 Supabase 密钥。前端只显示管理页面外壳，所有订单读取和签发操作由服务端验证管理员会话后执行。

## 首次部署

1. 在现有 Supabase SQL Editor 执行 `website/supabase/migrations/004_purchase_contact.sql` 一次，前提是 001–003 已执行。保留原订单、授权和恢复记录，不重跑旧迁移。
2. 在本机终端运行（只生成密码哈希，不联网、不需要支付或数据库配置）：

   ```powershell
   cd E:\susm-program\tab-copier\website
   node --experimental-strip-types scripts/create-admin-password.mjs
   ```

   输入两次自行保存的管理员密码，长度 16–128 字符，输入不会显示。复制输出的 `scrypt-v1$…` 整行哈希。
3. 在 Vercel 当前项目的 Production 环境新增 **Secret** `ADMIN_PASSWORD_HASH`，值填上述整行哈希，然后重新部署。登录时输入原密码，不输入哈希。保留已有 `TOKEN_DERIVATION_SECRET`、PayPal 和 Supabase 配置；不要为此更换授权签名密钥。
4. 打开 `https://tab-copier-sandbox.vercel.app/admin/recovery`。缺少管理员配置时接口拒绝访问，不会退化成公开管理功能。

## 日常处理

1. 用户在重装后的插件点击「恢复购买」，随后发送带参考编号的邮件。仅发普通问题邮件不会创建恢复申请。
2. 管理员登录页面，填写最新邮件中的 `TC-…` 参考编号，以及原订单的 PayPal **收款交易号**（`orders.provider_capture_id`）。可先在 Supabase 查找交易，不能把 PayPal 订单号填入此处。
3. 点击「核查订单」。服务端查找当前恢复申请，确认本地已付款、授权未撤销且未过期，再向 PayPal 检查收款商户、币种、金额、订单关联、capture 标识和完成状态。
4. 页面显示套餐、联系邮箱（未经验证）、原到期时间和目标参考编号。管理员需独立核实购买归属，再勾选确认并填写核查备注。参考编号、邮箱、交易号或截图本身不构成购买归属证明。
5. 点击「生成恢复链接」。服务端重新检查交易与授权，验证 5 分钟内的核查凭证，调用原有事务 `issue_recovery`。复制邮件回复并人工发给已核实的购买者。网页不自动发信。
6. 用户在链接页点击「确认恢复」，返回发起申请的同一插件，再次点击「恢复购买」兑换。页面文案里的“完成恢复”指这一步，不是额外的用户入口。

链接有效期由数据库决定（最长 24 小时，也受恢复申请有效期限制）。用户兑换后撤销旧安装授权，原套餐到期时间不变。无需重购。刷新管理员页面会丢失原始链接；尚未兑换时可重新核查和签发，新链接会取代旧链接。已兑换时不重复签发。

## 管理员验证

- 密码以带随机盐的 scrypt 哈希保存，仅服务端读取。验证使用常量时间比较，不把密码或环境密钥下发页面、URL、日志或数据库。
- 管理员会话一小时有效，采用服务端 HMAC 签名，并绑定部署 origin、密码哈希和用途。生产 HTTPS 使用 `__Host-`、Secure、HttpOnly、SameSite=Strict Cookie。
- 所有管理数据接口都检查会话；写操作要求请求 Origin 与 `APP_URL` 相同。登录每 IP 每分钟最多 5 次；核查每分钟 10 次；签发每分钟 5 次。限流复用现有数据库原子计数。
- 会话不能用作核查凭证，核查凭证不能换订单或恢复目标。生成时不信任前端传来的授权、金额、邮箱或订单状态。
- 退出会清除本浏览器 Cookie；修改 `ADMIN_PASSWORD_HASH` 并重新部署会让旧会话与核查凭证全部失效。单管理员版本不提供多管理员角色或逐条远程会话管理。
- 页面设为 noindex，不放入网站公开导航。隐藏入口不作为鉴权机制，匿名请求仍被接口拒绝。
- 管理员备注保存在 `recovery_tokens.operator_note`，不应包含密码或银行卡信息。系统不自动确认邮件发件人的身份。

## 购买邮箱

付款前必填购买联系邮箱，以订单字段 `orders.purchase_email` 保存。继续同一订单时复用原地址，不能通过重试覆盖；原有订单保持 null，可正常恢复。邮箱不发送给 Mixpanel，不用于营销，也不自动发邮件。本版不做邮箱验证码验证，不能凭邮箱匹配授予权益。
