## 操作与预期

- 点击查看 Pro：对话框居中，主要按钮完整显示；点击查看套餐时出现正在打开反馈，重复点击不会另建购买会话。
- 关闭购买网页，回插件再次查看套餐：重新进入原购买会话。已有订单时保留套餐并继续原 PayPal 订单，不生成第二笔本地订单。
- 尚未付款时点击检查购买结果：有检查中反馈；未开始购买与等待确认分别提示，不直接授予 Pro。
- 在网络检查尚未返回时切换格式、勾选列表、复制免费内容：本地操作仍可用，成功复制才扣额度。
- 用 Sandbox Personal 买家付款，回插件检查：后端核实 capture 后自动激活；无需输入授权码。
- 核对数据库：同一 purchase_id 只有一条订单和一份授权。确认退款后按原方案检查撤销。

本地回归覆盖慢网络不阻塞状态/复制、重复点击合并、继续原会话、跳转失败重试、一次性凭证更新和订单保留。实际 Chrome 显示与远程 PayPal/Supabase/Vercel 闭环需按上述步骤验证，不能由本地测试代替。

## 自动确认与状态同步补充

- 付款返回页自动串行重试，最多 12 次，间隔 5 秒（不含请求耗时）。确认成功或需要人工核查时停止；离开页面会取消后续请求，超出重试范围保留手动检查入口。
- 弹窗与设置页在首次读取状态前监听 storage，初始化期间收到的授权变化也会在加载后重新读取。自动激活后不必关闭弹窗刷新。
- 生效的 Pro 自动关闭升级提示、隐藏升级入口，移除已解锁选项的 Pro 提示标记。当前标签页不在标签组时仍禁用当前标签组，这是上下文限制。
- 本地签名授权联动测试覆盖：打开弹窗自动检查已付订单、验签激活、补收初始化期间的变化、付费分组/列表/去重输出以及本设备恢复后可用。
- 此补充无需新增 SQL 或变更密钥。重新部署网站、重新加载同一沙盒扩展即可；不需要重新付款。
