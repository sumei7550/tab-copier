## 目标与范围

证明沙盒付款到激活、复制范围/格式/配额、到期与退款撤销正确；证明失败可恢复且不会错误发放授权、泄露标签内容或重复扣次。不以购买意愿或转化率作为准入退出条件。包含 1.2 基础功能回归；不测未规划的云同步、模板、TXT、导入恢复。

## 执行顺序、准入和退出

先对格式/权益/日期和 API 事务做自动验证；再跑真实沙盒闭环与插件实机；最后在获授权后做正式小额受控验证。幂等性、并发、验签与环境隔离必须自动化覆盖；视觉交互补充人工证据。测试代码另行实现，本次不运行业务测试。

准入：需求版本冻结，迁移/设备/续购/离线/支持规则有明确决定；测试环境独立，接口可观察且脱敏，支付沙盒已配置。允许先验证不依赖未决规则的沙盒最小链路。

退出：所有收款到授权关键路径有环境和构建版本对应证据；无错误发放授权、未付解锁、重复延长、退款状态倒退、重复扣次及敏感数据泄露；付款成功但暂时自动激活失败可安全重试。阻断缺陷清零；正式账户/退款/生产数据库可用性未证实则不可发布真实收费。

人工恢复邮箱已确定；老用户策略、设备数量、重复购买和离线宽限采用开发设计建议值，正式发布前需冻结，对应测试标记待定；不能凭推荐方案给出通过结论。记录 build/commit、环境、时间、来源规则、操作结果和脱敏证据链接，失败重测保留原失败记录。

## 自动激活与人工邮件恢复补充

- 用原始 PayPal.cn 个人卖家接入路径创建真实 Sandbox REST 应用；不把开户入口当 API 基址，不混用 IPN 验证。
- 付款页无激活码/邮箱恢复表单；关闭网站后插件重新打开可自动获取授权，Web 与扩展会话凭证不互通。
- checkoutTicket 限时/单次/抗重放，fragment 清除；clientId/orderId 无法领内部令牌。
- /activate 超时后幂等重试，首次起算仅一次。Webhook 和 capture 并发不重复创建授权。
- 恢复入口显示真实 Outlook 地址，mailto 不可用可复制；不触发 Resend 或后台自动邮件。
- 管理员工具无匿名入口；无支付核查不得签发恢复链接。凭证扫描 GET 不消费，POST 确认才消费，重放、过期或错误请求秘密无法授权。
- 恢复绑定目标安装，替换旧 activation，原 expiresAt 不变；过期/退款/撤销不能被恢复或旧支付通知复活。
- 建议默认单设备、12h 刷新/72h 离线等仅在最终权益确认后作正式 oracle；不得把建议冒充用户已确认。
- 正式收费验证 Vercel 商用套餐、Supabase 可用性/恢复与商户收款身份；仅沙盒通过不足以发布。

## 客服入口更新（2026-11-27）

统一入口名称为“联系客服”，支持功能问题、付款与恢复购买。弹窗主操作“打开邮件应用”，通过 mailto 预填 sumei7550@outlook.com、主题“Tab Copier 客服支持”和可编辑问题模板；用户自行填写并发送，不自动发送。模板中付款邮箱和 PayPal 交易号仅在涉及付款/恢复时填写。不自动附带浏览数据、秘密凭证或付款详情。

保留复制邮箱和复制模板，处理默认邮件应用未配置的场景；不能承诺 mailto 在所有设备都能打开。“恢复购买”作为次要操作保留，上方说明“已购买？恢复 Pro 权益。”。点击先验证本设备凭证：有效则恢复；无凭证则引导联系客服；网络故障仅提示重试，不判断未购买。恢复本质仍是人工核实后的单次链接流程，不因改名降低鉴权。测试需核对中文主题/正文 URL 编码、用户确认发送、无邮件客户端备用入口、键盘焦点和恢复流程不变。

## 去重验收补充

验证弹窗/设置同值同步、仅尝试开启才出现升级提示、取消不写入开关；检查公共输出模块不被设置页或旧本地配置绕过。Pro 两处切换应同时改变预览与输出数量。重复 URL 保留已选第一条，未选的重复项不得压掉已选项；标题相同 URL 不同不合并。追踪清理开/关、不同有效参数、hash、参数顺序及空选择均覆盖。原始选中数与去重后输出数分别显示；无重复显示 0。到期回退、跨页面 storage 同步与老用户策略按确认口径验证。

## 支持序列号统一（最新交互）

普通反馈与恢复购买统一使用本安装的公开支持序列号 TC-随机安装标识。自动生成并随邮件/复制模板附带，用户不手动生成或填写；序列号不是付款、授权或购买归属证明，不是硬件指纹，重装可能变化。普通反馈只填问题描述，不要求交易信息，不请求恢复服务。点击“恢复购买”时才在内部建立私密恢复会话，UI 不再展示单独恢复编号；管理员用支持序列号定位有效会话，仍需独立核实付款归属。找不到会话时要求点击恢复购买，不凭序列号直接发授权。恢复接口仍使用独立私密凭证。

## 联系客服文案简化

不在用户页面展示安装标识或“支持序列号”及其解释。普通反馈和恢复邮件后台自动附带同一安装标识，邮件字段称“参考编号”；复制模板同样附带。页面仅保留联系、复制和恢复操作，成功反馈只说明已复制/请填写问题，不突出编号。测试需确保移除展示后没有遗留 DOM 引用，邮件/模板仍包含定位信息。该标识仍不能代替授权或付款归属验证。
