## 目标与范围

证明沙盒付款到激活、复制范围/格式/配额、到期与退款撤销正确；证明失败可恢复且不会错发码、泄露标签内容或重复扣次。不以购买意愿或转化率作为准入退出条件。包含 1.2 基础功能回归；不测未规划的云同步、模板、TXT、导入恢复。

## 环境与证据

| 环境/接缝 | 证明内容 | 证据与限制 |
| --- | --- | --- |
| 本地模块测试 | 格式转义、权益矩阵、配额边界、到期计算 | 输入输出/自动化结果；不能证明 Chrome 或真实支付 |
| Supabase 测试库+API 集成 | 事务、唯一约束、并发领取/激活、乱序事件 | 脱敏记录、约束与接口响应；模拟通知不能代替真实验签 |

## 核心验证矩阵

| 编号 | 覆盖 | 判定依据 |
| --- | --- | --- |
| T01 | 四种范围，未分组、无窗口、窗口切换、组删除 | 复制候选与实际浏览器范围一致；未分组提示准确 |
| T02 | 四种格式、普通/bullet/ordered/task、长标题与特殊字符 | 输出与预览同源；原始剪贴板准确；无脚本执行 |
| T03 | 每日 0/1/2/3 次、并发点击、失败、取消、跨日 | 只成功扣减，共享额度，不重复提交；本地软限制边界明确 |
| T04 | 免费/体验/30天/买断/过期/未知/旧安装 | 与权益表一致，popup/options/输出路径不能绕过；旧安装待口径冻结 |
| T05 | 篡改 plan/金额/币种/收款方、approved/pending 状态 | 服务端拒绝错款，未最终收款不发码 |
| T06 | 真实沙盒支付、Webhook 验签失败、延迟、重复及乱序 | 只有可信支付发码，一单一码，退款后旧成功事件不恢复授权 |
| T07 | 并发领码、丢 cookie、无/错误领取凭证、枚举订单号 | 无凭证无法领码；正确凭证刷新可领同一码；日志无秘密 |
| T08 | 首次/再次/并发激活，72h/30天边界 | 服务端首次激活起算，重放不延长，买断无业务到期时间 |
| T09 | 退款、撤销、断网、授权缓存过期、数据库暂停 | 退款按已定联网/离线策略生效；请求失败不误判未购买 |
| T10 | 限流、密钥隔离、签名伪造、sandbox 码用于 live | 无法伪造权益，数据库不被前端直接访问；环境互不信任 |
| T11 | 筛选/全选/刷新、清理追踪/去重、固定排除 | 与 1.2 基础行为比较，付费回退明确且预览同步 |
| T12 | 13 locale、键盘、焦点、380px/长文本/购买页窄屏 | 主操作可见，标签有名称，错误可恢复，不靠颜色独自表达 Pro |
| T13 | 分析事件、复制/支付失败脱敏 | ext_/web_ 前缀正确，无组名/URL/邮箱/授权秘密上传 |

## 执行顺序、准入和退出

先对格式/权益/日期和 API 事务做自动验证；再跑真实沙盒闭环与插件实机；最后在获授权后做正式小额受控验证。幂等性、并发、验签与环境隔离必须自动化覆盖；视觉交互补充人工证据。测试代码另行实现，本次不运行业务测试。

准入：需求版本冻结，迁移/设备/续购/离线/支持规则有明确决定；测试环境独立，接口可观察且脱敏，支付沙盒已配置。允许先验证不依赖未决规则的沙盒最小链路。

退出：所有收款到授权关键路径有环境和构建版本对应证据；无错发码、未付解锁、重复延长、退款状态倒退、重复扣次及敏感数据泄露；付款成功但暂时领码失败可安全重试。阻断缺陷清零；正式账户/退款/生产数据库可用性未证实则不可发布真实收费。

老用户策略、设备数量、重复购买、离线宽限和人工恢复渠道仍待确定，对应测试标记待定；不能凭推荐方案给出通过结论。记录 build/commit、环境、时间、来源规则、操作结果和脱敏证据链接，失败重测保留原失败记录。
