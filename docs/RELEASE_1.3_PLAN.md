# Tab Copier 1.3 版本计划

状态：2026-11-27 修订，可开始沙盒开发，尚未完成支付验证。授权细则以 docs/1.3/DEVELOPMENT_DESIGN.md 为准。基于 1.2.0。

## 目标

回应用户对 Chrome 标签组的需求，并实现已确定的收费方案：免费基础复制每日 3 次，Pro 解锁无限次数、标签组、去重和 Markdown 列表样式。开发和发布只以技术可实现性及运行可靠性为条件，不将付费意愿、购买转化或先发布免费版作为前置条件。

## 功能与权益

| 功能 | 免费版 | 有效 Pro |
| --- | --- | --- |
| 当前标签页、当前窗口、全部窗口 | 每天共 3 次成功复制 | 不限次数 |
| 普通 Markdown 链接、标题 + URL、仅 URL、HTML 链接 | 支持，共用额度 | 支持 |
| Markdown 无序列表、有序列表、任务清单 | 不支持 | 支持 |

## 复制范围与界面

- 用范围下拉框替换 All windows：当前标签页、当前标签组、当前窗口、全部窗口。默认当前窗口。
- 当前标签组取打开 popup 前活动标签所属的 Chrome 标签组；未分组时禁用并提示原因。
- 范围切换后刷新候选标签、选择状态和预览；不保留已离开范围的选中项。
- 保留格式选择及独立的 Markdown style 行。付费选项显示 Pro 标记；点击可查看权益，不默默启用或扣额度。
- 标签组范围显示组名；包含组名作为可选输出，组名需按输出格式正确转义。
- 顶部显示“今日剩余 3 次”和升级入口；额度耗尽后仍允许查看、筛选和预览。
- Pro 到期后保留用户偏好，但实际输出回退到当前窗口、关闭去重、普通 Markdown，并明确提示；预览必须与实际复制一致。
- 首次安装提供固定工具栏步骤，读取固定状态后隐藏提示；不承诺自动固定。

支付使用 PayPal 中国（paypal.cn）个人卖家账户，不再按普通 Personal 账户推断权限。官方个人卖家与集成指引确认，审核通过后可接入全球收单；先创建沙盒 REST 应用，集成 Checkout 与 Webhook。paypal.cn 是产品/开户入口，不是 REST API 基地址。现有账户审核、Live 权限和收款方标识仍需实际验证；账号与凭据不硬编码到仓库。

采用 Sandbox REST Checkout + Webhook，不混用旧式支付链接/IPN。若实际账户仅有付款链接而没有自动核款能力，保留沙盒开发成果，但不开放自动收费。

## 已确定的部署与自动授权

- Next.js App Router + Route Handlers（Node.js runtime），部署 Vercel；website/ 与扩展独立构建。
- Supabase 保存订单、授权、设备激活及短期会话。无用户注册/登录，不展示激活码，不发自动邮件，不接 Resend。
- 插件在购买前建立私密购买会话，与服务端订单绑定。网页只持短期购买入口；订单号与 clientId 都不能作为领取授权的秘密。
- 捕获与可信核款完成后原子创建授权。插件重新打开或有限重试时以购买凭证领取内部授权并自动激活；网页显示“付款已确认，请返回插件”。
- 关闭网页或 popup 不丢订单；通知延迟可重查，不以浏览器返回为付款依据。
- 内部凭证只保存在插件本地，服务端签名权益用于有界离线使用；不写网页、日志或埋点。
- 同设备凭证仍在时自动恢复。重装/换设备且凭证丢失，用户直接发邮件到 sumei7550@outlook.com，提供购买邮箱、PayPal 交易号和问题描述。
- 恢复入口提供复制邮箱、复制邮件模板和打开邮件应用；不建恢复申请表单或自动通知服务。用户没有邮件应用时可自行在网页邮箱发送。
- 人工核查真实交易及授权后，通过受保护运维工具生成短期一次性恢复链接，管理员手动回复。恢复不重置有效期；邮箱、订单号、截图不能单独证明归属。
- 数据结构包含 orders、licenses、activations、purchase_sessions/recovery_tokens，无 users 表；这取代先前两表与页面领激活码方案。细则见开发设计。

Supabase 免费版用于开发验证；正式收费前解决低活跃暂停、备份恢复与可用性。核实 Vercel 套餐适用于真实商用场景。

## 免费额度

- 所有格式和免费范围共用每天 3 次；以剪贴板写入成功为扣减依据。
- 空选择、无可复制标签、预览、筛选、刷新、格式切换和失败均不扣减。
- 防止连续点击造成并发超额或重复扣减；正常重复成功复制算新的一次。
- 按设备本地日历日重置，在界面说明“本设备每天”；跨时区/修改时钟不得反复发放同日额度。
- 免费次数是本地软限制，卸载/清除数据可能重置，不宣称防绕过；严格跨设备配额需账号与后端，不在本版范围。
- 本版无文件下载，故界面用“复制次数”，避免“导出”让用户误以为已支持保存文件。

## 老用户迁移：上线前必须确定

用户已决定去重和列表样式属于 Pro，但尚未明确老用户是否保留原免费权益。

建议：检测从 1.2 或更早版本升级的本地安装，保留原有基础复制不限次数、去重和列表样式；新增标签组仍需 Pro。新安装使用新规则。该保留权益仅限本地安装，不承诺重装或跨设备恢复；若需要可恢复权益，需另行设计账号认领。

如果决定所有用户统一限制，则应在首次更新时明确说明权益变化，不静默改变输出。此决定必须在实现迁移前确认。

## 埋点与隐私

沿用 ext_ 前缀，网站未来用 web_。记录范围变更、标签组复制成功、配额耗尽提示、付费功能点击、升级页展示、套餐选择、支付跳转、已验证权益激活、恢复购买及套餐到期。

记录 plan、scope、format、markdown_style、result、reason 等枚举及必要数量；不记录组名、标题、URL、复制内容、邮箱、支付会话地址或支付凭据。支付页返回不等于购买成功，权益事件必须由可信支付状态确认并去重。

更新隐私政策、商店披露与产品说明，区分标签内容本地处理、Mixpanel 分析、PayPal 支付，以及 Vercel/Supabase 保存的订单与授权数据。按实际接入增加最小权限与 MV3 后台逻辑，不远程执行代码。

3. 完成复制范围、权益、额度、多语言、恢复入口及固定引导；确定老用户规则后实现迁移。

## 去重入口及规则（2026-11-27 确认）

- 弹窗保留“移除重复 URL · Pro”；设置页为“默认移除重复 URL · Pro”。两处映射同一个 removeDuplicates 偏好，修改后同步，不创建互相覆盖的第二套值。正式实现跨页面用 storage.onChanged 同步。
- 进入设置或查看去重选项不弹付费；免费用户尝试开启才显示 Pro 说明，可看套餐或取消。取消不保存开启状态；Pro 直接切换并更新预览。权益判断在处理输出的公共模块执行，不能仅凭按钮/本地布尔值放行；旧用户按最终迁移政策例外处理。
- 顺序：候选范围/筛选/勾选 → 按 removeTracking 处理 URL → 开启且有权益时去重 → 生成预览和复制文本。对相同的处理后完整 URL 保留第一条，不按标题/域名/网页内容合并，不新增参数排序、hash 删除或路径大小写折叠。
- 开启时显示“已排除 N 个重复链接 · 将复制 M 条”，无重复显示 0；选中数量保持真实勾选数，与输出数量分开。关闭后保留所有已选项。
- 列表保留原始候选以便用户决定选哪个标题；去重作用于已选输出，不提前永久隐藏重复候选。这是相比 1.2 加载时去重的有意调整。Pro 到期或无有效权益后，保留偏好但停止执行并同步预览。
- 搜索属于查找，去重属于输出整理；本版不新增复杂高级过滤菜单。
- 原型含一对仅追踪参数不同的示例链接，可切换 Pro、去重和追踪清理查看效果；模拟设置不跨刷新持久化。

## 支持序列号统一（最新交互）

普通反馈与恢复购买统一使用本安装的公开支持序列号 TC-随机安装标识。自动生成并随邮件/复制模板附带，用户不手动生成或填写；序列号不是付款、授权或购买归属证明，不是硬件指纹，重装可能变化。普通反馈只填问题描述，不要求交易信息，不请求恢复服务。点击“恢复购买”时才在内部建立私密恢复会话，UI 不再展示单独恢复编号；管理员用支持序列号定位有效会话，仍需独立核实付款归属。找不到会话时要求点击恢复购买，不凭序列号直接发授权。恢复接口仍使用独立私密凭证。
