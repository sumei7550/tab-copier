## 暂定页面决策

- 预研不应承诺某个 slug 或最终页面数。
- 若必须给下一阶段提供可执行草案：优先研究“英语首页 + 简体中文首页”的本地化品牌/多标签复制/格式主题；是否需要独立 Markdown 或教程页，等量化词表与目标地区 SERP 核实后决定。
- 隐私页是信任/合规内容需求，不代表已证明其有独立自然搜索量。
- 不为 URL-only、标题+URL、HTML、每个用户职业/行业变体分别开页；它们应并入真实产品首页/功能章节。
- 不建“导出文件”“保存/恢复会话”“最佳替代品”等与当前产品不符或证据不足的专题页。
