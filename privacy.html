Privacy Policy

Extension: Tab Copier  ·  Last updated: November 27, 2026

Data Collection

Tab Copier does not collect an account, and it does not transmit tab titles, URLs, page content, or the text you copy. That information stays in your browser.

The extension sends pseudonymous usage events to Mixpanel so we can see which features are used. Each event can include a random identifier, your operating system, the extension version, your Chrome UI language, and details such as the output format and Markdown list style, whether all windows are included, whether tabs were selected, whether the preview refresh button or support link was clicked, how many tabs were selected or copied, and whether a filter was active. The words you type into the filter are not included. The request IP address is shared with Mixpanel for country and location inference.

Permissions

tabs: Used to read the titles and URLs of tabs in order to build the copy text shown in the popup. Those titles and URLs never leave your browser.

storage: Used to save copy preferences and the random analytics identifier on your device.

api.mixpanel.com host access: Used only to send the usage events described above.

Third-Party Services

Usage events described above are sent to Mixpanel (Mixpanel, Inc.) at https://api.mixpanel.com. Mixpanel’s privacy policy is at https://mixpanel.com/legal/privacy-policy/. Tab contents are not shared with Mixpanel or any other service.

Data Storage

Tab Copier stores copy preferences (such as output format and cleanup options) and a random analytics identifier in chrome.storage.local on your device. It never stores your tab titles, URLs, or copied content.

Purchases and Recovery (1.3 Sandbox)

The sandbox website stores a purchase contact email, the payer email returned by verified PayPal payments, plan, order and PayPal transaction identifiers, payment status, license dates, and a random extension installation identifier in Supabase. The website and APIs run on Vercel; PayPal handles payment. Manual recovery stores requests and operator review notes. Contact emails are unverified, are not sent to Mixpanel, and are not used for marketing. The sandbox sends no automatic email. Contact sumei7550@outlook.com for purchase-data questions or correction/deletion requests; ownership checks apply.

隐私政策

扩展程序：Tab Copier  ·  最后更新：2026年11月27日

数据收集

Tab Copier 不收集账号，也不会传输标签页标题、URL、页面内容或你复制的文本。这些信息只留在你的浏览器里。

扩展会向 Mixpanel 发送带随机标识的使用事件，用来了解功能是否被使用。每条事件可能包含操作系统、扩展版本、Chrome 界面语言，以及输出格式和 Markdown 列表样式、是否启用所有窗口、标签选择操作、是否点击预览刷新按钮或支持链接、选择或复制了多少个标签、筛选框是否有内容等细节。筛选框里输入的文字不会上传。请求会把 IP 地址发送给 Mixpanel，用于推断国家和地理位置。

权限用途

tabs：用于读取标签页标题和 URL，以便在弹出窗口中生成复制内容。标题和 URL 不会离开你的浏览器。

storage：用于在本机保存复制偏好和匿名统计用的随机标识。

api.mixpanel.com 主机访问权限：仅用于发送上述使用事件。

第三方服务

上述使用事件会发送到 Mixpanel（Mixpanel, Inc.）的 https://api.mixpanel.com。Mixpanel 隐私政策见 https://mixpanel.com/legal/privacy-policy/。标签页内容不会分享给 Mixpanel 或其他服务。

数据存储

Tab Copier 使用设备上的 chrome.storage.local 保存复制偏好（如输出格式和清理选项）以及一个随机统计标识，不会保存标签页标题、URL 或复制内容。

购买与恢复（1.3 沙盒）

沙盒网站在 Supabase 保存购买联系邮箱、PayPal 返回的付款邮箱、套餐、订单与 PayPal 交易标识、付款状态、授权时间和随机插件安装标识。网站及接口运行于 Vercel，PayPal 处理付款。人工恢复还保存申请及核查备注。联系邮箱未经验证，不发送给 Mixpanel，也不用于营销；沙盒不发送自动邮件。购买数据查询、更正或删除请求可联系 sumei7550@outlook.com，处理前需核实订单归属。
