Privacy Policy

Extension: Tab Copier · Last updated: November 17, 2026

Data collection

Tab titles, URLs, page contents, copied text, and filter text are not sent to any server. Tab Copier sends pseudonymous usage events to Mixpanel to measure feature use. Events may include a random identifier, operating system, extension version, interface language, selected output format and Markdown style, feature interactions, and tab counts.

Local processing

The extension reads tab titles and URLs to create the text shown in the popup. This processing happens locally in your browser. Copy preferences and a random analytics identifier are stored in chrome.storage.local. The extension does not require an account, sign-in, or cloud sync.

Permissions

tabs reads tab titles and URLs to create copy text. storage saves copy preferences and the random analytics identifier locally. Host access to api.mixpanel.com sends usage events and the request IP address for country and location inference.

Third-party services

Usage events are sent to Mixpanel, Inc. at https://api.mixpanel.com. The request IP address is used to infer country and location. Mixpanel's privacy policy is available at Mixpanel Privacy Policy. Tab Copier does not read page contents or send tab titles, URLs, or copied text.

Contact

Privacy questions: GitHub Issues.

隐私政策

扩展程序：Tab Copier · 最后更新：2026 年 11 月 17 日

数据收集

标签页标题、URL、网页内容、复制文本和筛选框文字不会发送到服务器。Tab Copier 会向 Mixpanel 发送带随机标识的使用事件，用于了解功能使用情况。事件可能包含随机标识、操作系统、扩展版本、界面语言、输出格式和 Markdown 样式、功能操作及标签数量。

本地处理

扩展程序读取标签页标题和 URL，以生成弹窗中的复制文本；这些处理在浏览器本地完成。复制偏好和随机统计标识保存在 chrome.storage.local。扩展不需要账号、登录或云同步。

权限说明

tabs 用于读取标签页标题和 URL 以生成复制文本；storage 用于在本机保存复制偏好和随机统计标识。对 api.mixpanel.com 的主机访问权限用于发送使用事件和请求 IP，以推断国家及地理位置。

第三方服务

使用事件会发送到 Mixpanel, Inc. 的 https://api.mixpanel.com。请求 IP 用于推断国家和地理位置。Mixpanel 隐私政策见 Mixpanel 隐私政策。Tab Copier 不读取网页内容，也不发送标签标题、URL 或复制文本。

联系方式

隐私问题请通过 GitHub Issues 联系。
