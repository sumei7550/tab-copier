Privacy Policy

Extension: Tab Copier · Last updated: August 3, 2026

Data collection

Tab Copier does not collect, store, or transmit personal data, browsing history, tab titles, URLs, or copied content.

Local processing

The extension reads tab titles and URLs only to create the text shown in the popup. Processing happens locally in your browser. The free version does not require an account, sign-in, cloud sync, payment, or remote server.

Permissions

tabs reads tab titles and URLs for the current-window copy workflow. storage saves copy preferences locally in chrome.storage.local. clipboardWrite copies the generated text to the clipboard.

Third-party services

Tab Copier does not send data to or share data with third-party services. It does not read page contents.

Contact

Privacy questions: GitHub Issues.

隐私政策

扩展程序：Tab Copier · 最后更新：2026 年 8 月 3 日

数据收集

Tab Copier 不会收集、存储或传输个人数据、浏览历史、标签页标题、URL 或复制内容。

本地处理

扩展程序只读取标签页标题和 URL，用于生成弹窗中显示的文本。所有处理都在浏览器本地完成。免费版不需要账号、登录、云同步、支付或远程服务器。

权限说明

tabs 用于读取当前窗口的标签页标题和 URL。storage 用于将复制偏好保存在本地 chrome.storage.local 中。clipboardWrite 用于将生成的文本复制到剪贴板。

第三方服务

Tab Copier 不会向第三方服务发送或分享数据，也不会读取网页内容。

联系方式

隐私问题请通过 GitHub Issues 联系。
