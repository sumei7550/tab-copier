## English full description

Tab Copier turns selected tabs in your current Chrome window into clean text you can paste into notes, documents, chats, or link lists.

Choose the tabs you need, preview the result, and copy one of three formats:

- Markdown links
- Title + URL text
- URL-only lists

Useful controls include:

- Select individual tabs or all available tabs in the current window
- Search and filter open tabs by title or URL
- Exclude pinned tabs
- Remove common tracking parameters locally
- Preview the generated text before copying
- Copy one tab or multiple selected tabs
- Open the extension with a Chrome keyboard shortcut
- Use the bundled interface translations offline

Tab Copier processes tab titles and URLs locally in your browser. It does not read page contents, collect browsing history, send tab data to a server, or require an account, sign-in, or cloud sync.

Chrome may restrict access to browser-internal and extension-internal pages. Those pages are shown as unavailable and cannot be copied.
