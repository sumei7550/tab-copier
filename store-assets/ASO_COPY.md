## 3. 详细描述（英文）

Tab Copier is a simple, private tool for turning browser tabs into useful notes and link lists.

Select tabs from your current window, preview the result, and copy it in the format you need:

- Markdown links for notes and documentation
- Plain text with title and URL
- URL-only lists for sharing and bookmarking

Features:

- Select individual tabs or select all tabs in the current window
- Search and filter open tabs
- Exclude pinned tabs
- Remove common tracking parameters locally
- Preview the generated text before copying
- Use a Chrome keyboard shortcut to open the extension
- Works offline with bundled language resources

Tab Copier is free to use. It does not require an account, sign-in, cloud sync, payment, or remote server. Tab titles and URLs are processed locally in your browser. The extension does not read page contents or collect browsing history.

## 8. 权限与隐私说明

- `tabs`: reads tab titles and URLs to generate the selected export
- `storage`: stores copy preferences locally in the browser
- `clipboardWrite`: copies generated text to the clipboard

The extension does not read page contents, collect browsing history, use analytics, call an AI API, or send data to a remote server.
