# Chrome Web Store listing copy

## Suggested title

Tab Copier - Copy Tabs as Markdown

## Short description

Copy selected tabs as Markdown, title + URL text, or URL-only lists. Preview before copying.

## Detailed description

Tab Copier turns selected tabs in your current Chrome window into clean text you can paste into notes, documents, chats, or link lists.

Choose the tabs you need, preview the result, and copy one of three formats:

- Markdown links
- Title + URL text
- URL-only lists

You can search open tabs, exclude pinned tabs, remove common tracking parameters locally, and open the extension with a Chrome keyboard shortcut. Tab Copier processes tab titles and URLs locally in your browser. It does not read page contents, collect browsing history, or send tab data to a server. No account, sign-in, or cloud sync is required.

Chrome may restrict access to browser-internal and extension-internal pages. Those pages cannot be copied.
